# 📎 OMNIMART

## 📌 Project Overview
OmniMart is a multi-vendor e-commerce platform that connects customers with different sellers in one place.
It allows customers to browse, search, and purchase products online with ease.
Vendors can create their own stores, manage products, and track orders.
The platform provides features such as shopping carts, product reviews, and order tracking.
Admins can manage users, monitor transactions, and track platform performance.
Our goal is to simplify online shopping and help businesses reach more customers.

## 🎯 Project Objectives

Project Objectives

- Create a user-friendly platform for online shopping.
- Connect customers with multiple sellers in one place.
- Help vendors manage their products, inventory, and orders.
- Provide easy product search, filtering, and comparison.
- Enable customers to track orders and review products.
- Provide administrators with tools to manage users and monitor platform activity.
- Support small businesses in reaching a wider audience.
